# نظام إدارة فحوصات مشاريع وزارة الأشغال العامة — مختبر مديرية أشغال محافظة مأدبا

منظومة هندسية متكاملة لحساب الحسميات والشذوذات المخبرية لمشاريع الطرق وفق أسس قبول المواد أو الأعمال وتعديل الأسعار للأعمال المنجزة في مشاريع الطرق (الإصدار 2023 م) — وزارة الأشغال العامة والإسكان / مديرية أشغال محافظة مأدبا.

## المميزات الرئيسية
- **بوابة النظام (`index.html`)**: تشمل النظام الهندسي، الدليل الإرشادي، وفريق العمل.
- **إدارة المشاريع والتقارير**: سجلات تراكمية مستقلة لكل مشروع، وإصدار تقارير رسمية بصيغة A4.
- **مراسلات المختبر**: إصدار مذكرة داخلية رسمية لمدير الأشغال بالفحوصات المحددة، مع معاينة وطباعة A4 وتصدير Word (`.docx`).
- **الحاسبات الهندسية**:
  - الحاسبة الشاملة للحسميات (المعادلتان 1 و 2 والجداول 1–16 مع نسختي جدول 10 و 15 قديم/معدل).
  - حاسبة سماكة الخلطة الإسفلتية (الجدول رقم 4 — كورات التنفيذ وضبط الجودة).
  - حاسبة درجات رك الإسفلت (البند 2.2.4 — أقسام مستقلة لكورات التنفيذ وضبط الجودة ولجنة الاستلام، مع اختيار نوع الطريق والجدول 10/15 قديم أو معدل).
  - حاسبة سماكة الفرشيات وحفر الاختبار (البند 2.1 والجدول رقم 1).
- **تصدير الملفات**: تصدير حقيقي إلى Excel (`.xlsx`) وWord (`.docx`) وCSV وطباعة A4 في صفحة واحدة.
- **المزامنة السحابية**: تخزين محلي (`localStorage`) مع مزامنة سحابية عبر **Cloudflare Worker + D1 Database** (`https://madaba-lab-api.ahmadalzan92.workers.dev`).
